# Explanation video script (about 6–8 minutes)

1. **Intro (30 s):** Name, project title, goal: help market strategists, BI analysts and researchers understand the EV market.
2. **Dataset (45 s):** Kaggle EV Market dataset, 300k rows, 37 columns; mention it is synthetic. Show the CSV briefly.
3. **Data preparation (1 min):** Show `data_preparation.py`: combine splits, impute nulls, derived bands. Show the Tableau data source, folders and calculated fields.
4. **Visualizations (1.5 min):** Walk through 4–5 key sheets: sales by category, manufacturer share with Top-N parameter, battery adoption, range box plot, map.
5. **Dashboards (1.5 min):** Demonstrate filters (year, region, battery), click-to-filter actions, phone layout.
6. **Story (1 min):** Click through the 7 scenes, reading each insight caption.
7. **Performance (30 s):** Show the performance-recording result and the counts of filters, calculated fields and visuals.
8. **Web integration (45 s):** Run `python app.py`, open Dashboard and Story pages showing the embedded Tableau views.
9. **Conclusion (30 s):** Top 3 insights + recommendations; mention the GitHub and Tableau Public links.

Record with OBS Studio, Loom or the Windows Game Bar (Win+Alt+R); upload to YouTube (unlisted) or Google Drive and add the link.
