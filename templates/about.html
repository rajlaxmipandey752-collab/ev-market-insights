About the Project

Dataset: Electric Vehicle Market Classification Dataset (Kaggle, MIT licence) - 300,000 synthetic EV records, 37 columns covering battery, range, performance, charging, price, safety, sales and customer rating. Manufacturer and model names are fictional.

Pipeline: Kaggle CSV → Python/pandas cleaning (data_preparation.py) → Tableau Desktop/Public (calculated fields, sheets, dashboards, story) → Tableau Public → Flask web app (Tableau Embedding API v3).

Tools: Tableau Public, Python 3, pandas, Flask, HTML/CSS.
